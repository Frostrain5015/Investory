加权平均成本法

按时间顺序遍历全部交易记录，逐步累加或摊薄成本：

// 买入操作 totalInvested += shares × price + fee totalShares += shares avgCost = totalInvested / totalShares // 卖出操作（按比例移除成本） soldCost = totalInvested × (sellShares / totalShares) totalInvested -= soldCost totalShares -= sellShares

分红摊薄成本

考虑已收分红后的真实持仓成本：

// 计算摊薄成本 effectiveInvested = totalInvested - totalDividends dilutedCost = effectiveInvested / totalShares // 已实现盈亏 realized += sellProceeds - soldCostBasis realized += Σ dividends

PnlLedgerService — 全系统最复杂算法

从第一笔交易日起，逐日模拟持仓变化，计算每日真实市场盈亏（剔除转入转出影响）：

for each trading day: ① 处理当日交易（买入/卖出） ② 处理当日分红 ③ 获取收盘价 → 逐日盯市 ④ dailyPnl = todayExTransfer - yesterdayExTransfer ⑤ 更新现金余额（含/不含转入）

PositionState — 每只股票独立追踪：

shares · costBasis · cash · dividends

关键设计 — 排除转入转出：

todayExTransfer = 股票市值 + 不含转入的现金
确保 P&L 仅反映真实市场波动

累计收益曲线

逐日遍历，预加载全部股价数据（批量查询，避免 N+1），每日计算组合总市值 + 现金 + 累计分红。
