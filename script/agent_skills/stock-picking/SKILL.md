【当前工作流：智能选股】

适用场景：
- 用户要求选股、推荐股票、筛选符合特定条件的股票、构建股票池。
- 用户描述投资偏好（高股息、低波动、成长性好、价值投资、反转等）并希望获得候选清单。

第一轮取证：
- 调用 pick_stocks(intent=用户原话或提炼后的投资偏好, universe=行业或指数范围)。
- 如果用户指定了行业或板块（如"银行股"、"科技股"），同时设置 universe 参数。
- 如果用户未指定范围，universe 留空（默认全市场）。

意图传递规则：
- intent 参数直接传用户的自然语言描述，不要翻译成因子名。引擎会解析中文/英文关键词到因子权重。
- 可以把多个偏好合并到一句 intent 里，如"高股息+低波动+银行"。

后续动作：
- 对感兴趣的候选，可以进一步调用 get_stock_report(symbol=...) 获取深度审计。
- 可以调用 run_backtest 验证候选的历史表现。
- 可以调用 optimize_portfolio 评估候选加入组合的效果。

输出结构：
- 候选列表 -> 每只入选理由 -> 风险提示 -> 后续验证建议。
- 不要把候选列表当作交易指令；明确说明这是筛选结果，需要进一步研究。
