## 保留数据如何继续使用

`script/index_archive.py` 使用只读SQLite文件保存国内指数原始OHLC及旧供应商成交量，默认 `data/index-history.sqlite`，可通过 `INVESTORY_INDEX_ARCHIVE` 指定位置。文件是长期归档，不属于64MiB可淘汰行情缓存，也不会被普通部署覆盖。

历史网关将国内指数请求按五周年日期拆分：旧段优先读取归档，新段使用同花顺；归档范围外继续使用原有备用网络路径。每根数据保留来源，要求日期有序且不重复，不做价格缩放或复权。归档安装/替换会改变Python缓存键；运行服务应在安装归档后启动或重启，避免旧Java内存缓存延迟生效。

归档不凭空补交易日，不保证旧供应商原本的数据完整。原始成交量单位仍标记为 `legacy_provider_units`，不能据此宣称所有指数成交量已完成统一口径校准。当前指数代码和元信息保持精确对应，不用同名ETF替代指数点位。

## 维护操作

所有步骤均为手动维护命令，不在应用启动、部署或定时任务里自动执行。使用项目私密 `script/config.ini` 或 `DB_*` 环境变量；不要把密码放在命令行。执行位置必须明确是待处理的Investory实例。清理前先部署不再访问旧行情表的版本，确认旧抓取进程已经结束。

以下为操作顺序，需使用正确数据库配置和足够空间的独立备份目录：

```powershell
python -X utf8 script/retire_price_store.py inspect
python -X utf8 script/retire_price_store.py prepare --as-of 2026-10-24 --directory D:/Attention/price-retirement-2026-10-24
python -X utf8 script/retire_price_store.py verify --directory D:/Attention/price-retirement-2026-10-24
python -X utf8 script/retire_price_store.py install --directory D:/Attention/price-retirement-2026-10-24
```

`inspect`只有查询，列出国内价格行数和每只指数保留区间的实际首末日期、行数；没有旧指数数据时明确显示0，不宣称已保留不存在的数据。`prepare`创建全量国内价格回滚备份、指数专用归档和校验清单，禁止覆盖已有目录。`install`只安装已验证归档，不删除数据库。

安装归档后，使用新版本验证一个归档区间、一个近期区间和跨五年边界的指数查询，再执行：

```powershell
python -X utf8 script/retire_price_store.py apply --directory D:/Attention/price-retirement-2026-10-24
```

工具在表写锁内重新比较原始行情与备份的内容摘要；结构、证券身份、数据内容不符或仍有新价格写入时停止，不执行删除。仅按备份中的国内证券ID和快照高水位删除已备份记录；检查目标记录归零后生成 `applied.json`。

MySQL按5000行分批提交。异常发生时可能已经删除部分批次，必须依据备份恢复；不能把工具异常自动理解为全程数据库回滚。外键仍引用价格行时工具拒绝操作。

## 回滚与磁盘空间

**代码回滚不会恢复已删除的数据。** 回滚需要保留独立备份和清单，再运行：

```powershell
python -X utf8 script/retire_price_store.py restore --directory D:/Attention/price-retirement-2026-10-24
```

恢复只写旧行情；按证券ID与交易日核对已存在记录，遇到不同价格停止覆盖。因价格行无业务外键，恢复可重新分配自增ID，避免撞上清理后新记录的主键。备份文件保留原始ID用于审计。目标MySQL的锁定、删除及空间回收已验收；完整生产备份未进行全量恢复演练，恢复及重复恢复仅在独立MySQL测试库验证通过。

DELETE通常只释放InnoDB内部可重用空间，不会马上缩小系统上的文件。确认恢复验证可行后，在维护窗口显式整理价格表：

```powershell
python -X utf8 script/retire_price_store.py compact --directory D:/Attention/price-retirement-2026-10-24
```

MySQL执行 `OPTIMIZE TABLE stock_prices`，可能重建表并需要额外临时空间；工具不触碰其他表。不能在实际执行并比较前后磁盘占用之前宣称已释放约3GB。

云端对应运行归档位置默认为 `/opt/investory/data/index-history.sqlite`，备份位于独立的 `/backup/` 目录。用户已明确下达部署指令，允许执行本次部署及此前指定的国内行情清理。
