# v6.3.3

范围：2026-10-20 架构梳理、代码清理及本次云端发布。

- 前后端、桌面清单及依赖锁文件统一为 6.3.3；页面版本来自前端 package.json。
- 清理与业务修复详见 [代码梳理记录](../code-hygiene-2026-10-20.md)。
- 合入 [A/HK 抓取零写入修复](../operations/crawl-zero-rows-2026-10-20.md)：指数代码隔离、结束日边界、信源就绪探测与状态区分。
- 云端仅更新 Java 应用及 Python 运行代码，保留数据库、脚本 config.ini、引擎缓存/数据及已有 HTTPS/反向代理配置。
- 部署使用 SSH alias 的密钥和已有 known_hosts 校验；先上传到独立发布目录，核对 SHA-256、检查服务端 Python 语法，再备份旧代码。
- 部署前后两次检查活动采集/回测/智能体任务；有任务运行时拒绝切换。停服切换后检查应用、引擎及 JAR 校验和；失败自动恢复旧文件并重新检查服务。
- 云端 `/opt/investory/release.json` 记录版本、提交、文件校验和；发布目录中保留对应 `backup/`。本地回执写入被忽略的 `backend/target/cloud-deployment.json`。
- `python deploy.py --no-build` 要求本地源码已提交且 HEAD 与 origin/master 对齐；此命令不会创建 GitHub 桌面发行版。

发布前验证：Java 29 项通过、3 项外部集成测试跳过；Python 20 项通过；前端类型检查、ESLint、导入图检查通过；Maven clean package 通过。

补充本地浏览器验证：桌面和手机宽度均能显示待发布、无变更、成功、失败四种状态；桌面页脚版本为 v6.3.3。该验证使用独立的模拟 API，无未捕获页面异常，不代表已完成云端全市场补抓。

云端验证包括应用/引擎健康状态、JAR 文件校验和，以及公网页面加载的版本资源。具体部署提交与时间以云端 release.json 和本地回执为准。
