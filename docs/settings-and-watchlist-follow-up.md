# 设置更新与自选列后续工作

更新日期：2026-10-22。

## 本次设置行为

- 暗色样式使用 ThemeProvider 的 `.dark` 类，弹窗标题栏使用与正文一致的不透明表面色。
- 移除量化分析列开关、浏览器偏好读写、自选页评分请求与相关条件列。研究页的独立因子分析能力继续使用现有接口。
- 观澜使用统一表单，支持最多 3 个独立模型：每个模型分别保存 API 协议、接口地址、密钥、Model ID、上下文窗口。无共享端点、模型和密钥回退，不替换用户填写的模型名称。
- 支持 OpenAI Chat Completions 兼容接口、Anthropic Messages。模型须支持观澜需要的流式输出和工具调用；不支持的服务会返回调用错误，协议兼容不代表所有模型都具备这些能力。
- 不需要鉴权的本地服务可不填密钥。同协议同地址下省略密钥保留原值，显式空字符串清除；协议或地址改变不会沿用原密钥。
- 本地接口由后端进程访问。远程后端的 localhost 不是用户桌面；使用本机模型需让业务后端运行在能访问推理服务的环境。
- 补充说明收纳到字段旁的 ⓘ，支持悬停、键盘聚焦、手机点击。错误和即将清除密钥等操作状态直接显示。

## 上下文预算

V8 迁移新增 `ai_model_profiles` 和 `ai_model_selection`，以每用户 1–3 的槽位约束模型数量。旧记录迁入槽位 1，上下文为 NULL，必须由用户补填保存后才能调用；不得为旧记录默填模型或窗口。保存第一个手动配置后可直接使用；删除当前模型后不会静默切到其他模型。

对话输入区右下角提供模型切换菜单，选择由后端按用户保存并在设置页与对话间共享。每条消息携带选中的模型 ID，后端立即读取并固定这一条消息使用的配置；可选标题生成也使用同一快照。生成过程中切换只影响下一条消息。菜单支持键盘方向键、Home/End、Escape、焦点返回和系统减少动态效果偏好，使用弹簧展开及选中标记过渡。

每次模型调用，包括工具结果续轮及可选标题生成，均使用用户选择的模型与窗口。回复上限取窗口四分之一，最低 256、最高 4096 tokens，另留 512 安全余量。输入按 UTF-8 字节和消息/工具开销保守估算，不假定所有供应商共用 tokenizer。保留系统指令和当前完整工具调用链，优先删除较早完整轮次；当前内容仍过长时停止调用，提示缩短输入或调整窗口，不截断成失配的工具消息。

该估算可能比供应商实际 token 数偏大，尤其是中文和工具较多时。窗口较小可能连固定提示词和工具定义都容纳不下；此时给出错误，不自动提高窗口。该选项不改变模型服务的 KV cache、权重、量化、显卡卸载或并发设置，不能作为显存用量保证。

## 外部 MCP 退役

移除服务端控制器、工具注册、确认存储、令牌 DAO、授权页及登录拦截器中的 Bearer 身份注入；移除白名单和 Frost ID 回调中的 MCP 返回路径。Frost ID 的应用登录及桌面深链接兑换继续保留。

V4/V5 是已经发布的 Flyway 历史，不修改或删除，以免现有数据库校验失败。旧 MCP 表不再被代码使用，数据清理另行迁移评审。发布前备份模型设置和迁移历史；经用户明确授权部署后，由 Flyway 正常应用 V8。构建时使用 clean，避免删除源码后旧 MCP class 仍残留于 target。云端私密配置不进入 Git 或发布文件覆盖清单；旧单模型设置迁移完成后，在用户保存或删除模型配置时移除对应旧记录，避免残留第二份密钥。

## 后续：自定义自选列表数据列

本次只删除旧开关，不引入替代开关。后续单独设计：

1. 用户可选择显示字段、顺序、列宽和固定列，提供可恢复的基础布局。
2. 按用户、列表保存偏好，手机端有独立显示规则；旧浏览器中的 `showRiskMetrics` 值不再读取。
3. 每一列记录数据源、口径、更新时间和缺失状态，不用一个总开关绑定全部量化数据。
4. 按所选字段请求数据，支持独立加载、缓存和失败提示；较慢的分析不能阻塞报价。
5. 在字段目录和接口契约评审后，再决定引入评分、风险、估值或用户自定义指标。
