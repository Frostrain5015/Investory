# 同花顺金融 API 可靠性与行情库脱离评估

评估时间：2026-10-22，17:03–17:05（上海时区，收盘后）。生产基线为 v6.3.6。本次只读，不修改应用代码、数据库、连接配置或云端服务。

## 结论

可以开始取消**沪深股票现价成功路径对本地行情表的冗余读取**；保留失败兜底。暂不关闭 MySQL 连接池，不删除 `stock_prices`，不停止仍支撑历史图表、回测和净值重建的数据路径。

这项结论的依据是接口返回字段足以独立完成现价与当日涨跌展示，加上代码确认的无条件 SQL 冗余。它不是长期可用性、盘中逐股时效或全市场覆盖认证。

## 实测结果

探针从当前阿里云服务器访问供应商 REST API，不借用应用缓存。主测试记录 15 次请求，跨 92.25 秒；股票与指数各按 30 秒间隔重复四轮，其余为历史、复权、日历和名称查询。

首次探针有一次自身变量命名问题，未能归档请求结果；该次未纳入主测试成功率，也未作为上游失败。修正后的主测试无探针错误。

## 当前数据库依赖与可拆范围

| 路径 | 当前事实 | 可采取的动作 |
| --- | --- | --- |
| 持仓现价、当日涨跌 | `HoldingService` 已批量取报价，但随后每只股票仍无条件调用 `findLatestTwo` | 将本地行情查询移到确有需要的兜底分支；完整同花顺报价走零行情 SQL 的正常路径 |
| 自选现价、涨跌 | `WatchlistController` 已取得 `priceQuotes`，仍无条件读最近两日收盘 | 同上；不能关闭自选记录、股票身份与用户权限所用业务数据库 |
| 世界市场 | 成功的新来源路径已不读旧价格，只有失败兜底才查询最后收盘；其余 21 个境外指数/指标未被同花顺替换 | 保留当前故障回退，不扩大到未验证标的 |
| K 线、迷你走势图、基准比较 | `ChartDataController` 仍读 `stock_prices`，包含历史最早日期和基准价格 | 可作为下一批接口适配试点；需统一周期、复权、成交量与缓存口径，再切读取来源 |
| 回测 | `script/backtest_engine.py:load_ohlcv` 直接查询本地 OHLCV | 未完成数据适配和可重复性验证前不能断 |
| 历史净值与盈亏重建 | `PnlLedgerService` 查询历史价格，`PortfolioValueCalculator` 由其重建净值 | 先建立有版本和日期口径的历史数据读取层，再考虑切源 |
| 账户、持仓、交易流水、分红、会话等 | 属于用户业务数据，供应商行情 API 不提供这些记录的替代存储 | 继续保留数据库连接及数据 |

明确的首批代码位置：

- `backend/src/main/java/com/investory/service/HoldingService.java`：`findLatestTwo` 在实际读取 `quote` 之前无条件执行。
- `backend/src/main/java/com/investory/controller/api/WatchlistController.java`：`findLatestTwo` 在已取得报价之后仍无条件执行。
- `backend/src/main/java/com/investory/controller/api/ChartDataController.java`、`backend/src/main/java/com/investory/service/PnlLedgerService.java` 和 `script/backtest_engine.py` 是当前不能直接删表的实际读取者。

## 行情表体量

云端 `information_schema.tables` 显示 `stock_prices` 约 25,393,235 行（InnoDB 估计），数据与索引合计约 3.009GiB。这个体量属于行情表，不能等同于整个数据库。此次未执行全表 COUNT、DDL、删除、断连接或停止采集。

## 建议执行顺序

1. 先移除上述成功报价路径的冗余行情 SQL；自动测试需断言完整报价不调用价格 DAO，缺价仍进入原兜底。
2. 将 A 股 K 线和迷你走势图接入统一历史数据适配层，明确 `adjust=none/forward/backward`。首批限定已验证的沪深股票，旧表保持可恢复。
3. 补足完整交易时段、停牌/新股/退市、跨年复权和额度/故障恢复验证，并核对历史净值及回测结果。
4. 所有实际读取者完成迁移后，再评估停采、行情表只读归档或删除；不要以 92 秒的成功样本批准整库删除。

尚未验证：盘中逐股延迟、长时间可用性、并发用户吞吐、额度耗尽、服务等级承诺、全市场完整性、退市与历史代码覆盖、独立复权正确性。官方文档存在全市场导出能力，但本次未下载全市场数据，也未据此证明可以替代所有历史消费者。
