# 第二批迁移：最新报价读路径

本批在上一轮观澜历史日线、估值迁移的基础上实施。本记录描述本地修改和验证阶段，纳入 v6.3.7 发布；部署结果以云端 release.json 为准。迁移未删除或修改真实数据库数据。

## 已断开的行情表读取

| 入口 | 本批变化 |
| --- | --- |
| 首页、持仓 `/api/holdings` | `HoldingService` 移除 `StockPriceDao`，不再每只股票查询最近两日收盘价 |
| 自选 `/api/watchlist` | 移除 `StockPriceDao`，共享服务批量获取报价；缺价返回 null |
| 股票搜索 `/api/stock/search` | 参考价使用共享报价服务，一次批量读取，缺价保留 null |
| 个股详情 `/api/stocks/{symbol}` | 最新价格、涨跌和时间均来自报价快照，不再用数据库日期填充 |
| 轻量报价 `/api/quote/{symbol}` | 移除本地收盘价兜底，无法获取报价时明确返回 unavailable/null |
| 观澜 `get_stock_price` | A 股股票改用同花顺快照，不查询 `stock_prices` |
| 观澜 `get_portfolio`、`get_watchlist` | 持仓、自选关系仍读业务库，A 股报价使用同花顺批量快照 |
| 观澜组合分析和组合报告 | 复用新组合估值，按当前市值计算权重，替代原先按投入金额计算的权重 |

Java 路径沿用 `RealtimeQuoteService` 的同花顺优先、其他网络源后备和最长 24 小时内存保留报价机制。本批没有全局删除其他网络行情源。

Python 在共享适配器新增快照方法：每批 50 只，单次最多 500 个唯一标的，缓存最多 4096 个条目；成功和缺失条目均缓存 25 秒，缓存起点为请求开始，沪深旧代码及带交易所后缀的别名共享缓存。进程内限流沿用上一批实现，非 Java/Python 跨进程全局配额。Python 保守返回 `live=false`，上游时间明确属于批次，不能证明单标的实时性。

Python 仅将 A 股股票送入同花顺股票端点；港美股、指数、ETF 等不支持的资产保留显式数据库路径。不能据此声称所有资产的观澜行情都已脱库。

## 缺价、估值和后台读取

- 自选、搜索、个股最新价缺失时保留 null，不填零，不用历史图表最后一个收盘价冒充最新价。前端已适配 nullable 类型。
- Java 持仓聚合暂保留原有成本估值兜底，标记 `priceSource=cost`，通过既有注意图标的悬浮说明解释；不据此生成当日涨跌。此值用于聚合连续性，不代表市场报价。
- Python 组合估值缺少报价或必要汇率时返回 `valuationComplete=false`、`unpricedSymbols`，总资产与权重为空，组合分析不在缺价条件下继续生成权重。
- 多币种组合的汇总市值和权重统一折算为 CNY，汇率仍取业务数据库。原始币种价格和市值保留。
- `/api/holdings?quotes=false` 只复用有效内存报价，不触发网络请求；冷缓存会明确成为成本估值。后台风控预加载和投研风控页面均阻止将成本估值当作市值权重。
- 前台原有 30 秒轮询和逐值变化动画保持，未增加每行来源或时间文案。

## 本地验证

新增 `QuoteReadPathTest`：H2 内仅创建股票、持仓、自选和汇率等业务表，刻意不创建 `stock_prices`。验证正常报价、缺价、不完整昨收、元数据读取、自选批量、搜索 null/时间序列化、个股详情及轻量报价。

另外增加内存报价读取不触发网络和过期验证；Python 增加批量上限拆分、别名复用、25 秒过期、缺失数据、缓存隔离、无行情 SQL、当前市值权重及非 A 股边界测试。

实际只读接口检查（2026-10-22 收盘后）：

- Java：真实同花顺客户端、真实共享报价服务，业务数据使用 H2 测试持仓，历史行情表不存在；持仓、自选、搜索、详情、轻量报价均通过。两只股票共发出两次提供方请求，其他网络源未使用。
- Python：业务关系使用隔离测试数据，真实调用同花顺；组合、自选、最新价三个工具复用一次两股票批量请求，价格一致，无 A 股历史行情 SQL。

## 仍未迁移

个股历史图表和列表迷你曲线、盈亏历史回放、策略回测、旧量化计算、部分其他观澜工具、世界行情最终数据库后备，以及批量抓取写入均保持现状。股票基础资料、交易流水、成本、分红、汇率等业务数据仍依赖数据库。

因此，已迁移的最新报价入口可脱离 `stock_prices`，但整个页面或整个应用尚不能断开该表，不能停掉 MySQL 或删除历史价格表。
