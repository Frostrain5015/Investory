# DeepSeek Search 辅助网络搜索

核验与本地改造日期：2026-10-22。确认采用 DeepSeek 的独立 Search API 作为观澜辅助网页搜索来源；结构化行情仍由同花顺金融API通道提供。两者不互相替代，也不要求推理模型必须使用 DeepSeek。

## 接口与范围

官方提供 `POST https://api.deepseek.com/v1/tools/search`，Bearer API Key 鉴权，返回有来源网址、标题、相关摘要和可空发布时间的结构化结果。[官方 Search 契约](https://api-docs.deepseek.com/api/search/)

既有观澜代码已包含这一调用入口。本轮将传输和响应处理拆到 `script/deepseek_search.py`，`ai_agent.tool_web_search` 继续是观澜工具入口，未重写 Agent 框架。

历史澄清：更早版本采用 Python requests 调用博查主搜索，并在失败时回退到经代理访问的 Tavily；提交 `d0dbfcf`（2026-10-20）已将其迁移至 DeepSeek Search。2026-10-22 的工作属于模块拆分、参数/错误处理补强、本地配置和验收，不是首次更换搜索供应商。

搜索链路清理复核：旧博查/Tavily 函数、降级分支和示例配置已不在当前源码；移除了遗留的 DuckDuckGo 提示词名称及拆分后没有独立职责的 `_deepseek_search` 转发函数。当前入口直接调用 `deepseek_search.search`；仍在使用的密钥读取、工具注册、任务调度、引用渲染以及通用 requests/代理依赖继续保留。该结论仅覆盖搜索链路，不能推导为整个仓库已完成死代码审计。

- 请求限制：非空关键词最多 128 个 Unicode 字符；本应用每次 1–10 条结果，默认 5 条。
- `need_content=false`，优先使用相关长摘要，缺失时使用 snippet；每条最多 1000 字，避免先取整页再截取开头遗漏相关内容。
- 保留标题、URL、发布时间、相关性及权威级别；空结果与查询失败分开。外部文本标记为不可信资料，不是程序操作指令。
- 不抓取返回网址、不执行网页内容、不调用 Fetch API；请求端只访问 DeepSeek API，海外站点由供应商搜索。实际网络可达性和覆盖不能承诺所有站点都可访问。
- 校验参数再请求；4 秒连接、12 秒读取超时。鉴权、余额、限流、网络及格式错误返回脱敏状态，不把服务商正文、异常字符串或密钥拼给模型。由于请求可能已计费，不做无条件自动重试。

## 本地私密配置

优先级：环境 `DEEPSEEK_SEARCH_KEY` → 已被 Git 忽略的 `script/config.ini` 的 `[search] deepseek_key` → 环境 `AI_DEFAULT_KEY`。末项只有明确是 DeepSeek 账户密钥时才可使用，不会自动取其他推理供应商的用户密钥。

本轮按用户明确要求写入本机 `script/config.ini` 的搜索配置，保留其他配置；不在本文、源码、测试数据或命令参数中保存真实密钥。该文件不会随普通 Git 提交、后端 JAR 或前端打包自动发布。云端启用仍需独立配置及用户部署授权。

## 价格与边界

2026-10-22 官方价格为 Search 每 1000 次成功请求 **0.75 美元**，Fetch 单独按同价计费；不将它固定写成“人民币 5 元”。官方另有面向特定客户端的服务端工具调用临时优惠说明，不把优惠套用到本项目的直接 REST 调用。[官方价格](https://api-docs.deepseek.com/quick_start/pricing)

网络搜索用于新闻、公告线索和辅助证据，不能代替交易所行情、实际持仓或历史时点财报。相关性/权威分数不构成事实正确保证；引用仍须核对来源和日期。

## 验证

五项离线测试验证了参数不合法/无密钥时不请求、摘要裁剪与引用保留、鉴权/余额/限流错误不重试、空结果与异常区分、敏感错误脱敏、危险 URL 丢弃和不主动访问来源站点。

真实验证通过 `ai_agent.tool_web_search` 读取本机私密配置，使用国内公开资料与海外 SEC 站点两个查询；结果及耗时见 [2026-10-22 验证记录](data-and-search-validation-2026-10-22.md)。这属于本机只读验证，不证明线上服务已经使用该配置。
