# v6.3.5 世界市场接入验收

日期：2026-10-22。范围为同花顺金融 API 的首个业务接入及设置页切换动画；本版不改持仓、历史 K 线、台账或交易能力。

## 已验证

- 供应商真实请求：三个 A 股指数在同一快照请求中返回成功，HTTP 与业务 code 均成功。最初 HTTP 探测约 413ms；随后使用真实 Java 适配器、世界市场服务和 MockMvc 端点的独立验收约 615ms。这是单次样本，备用海外来源为模拟对象，不代表整页延迟或 SLA。
- 本地有界 HTTP 测试：指数使用专用路径，校验代码、BigDecimal、百分比、空值及批次时间；原检索、股票快照、历史日线的错误、超时与权限测试保留。
- 服务测试：三个指数一次批量取得，多个调用者共享 90 秒缓存；缺行仅回退缺失项；限流不即时重试；保留报价使用原接收时间，超过 24 小时不再作为内存兜底；通道关闭不请求供应商，缺失值保持 null。
- 旧来源测试：本地收盘按完整代码精确匹配，传递实际交易日；Yahoo 使用交易所时间，缺少前收盘时涨跌额、涨跌幅保持 null。
- 完整 Maven `clean package` 成功：88 项测试，83 项通过，5 项按设计跳过（3 项采集集成测试、2 项外网测试）。独立启用的新真实指数验收 1 项通过。Python 离线回归 31 项通过。前端类型、lint、import graph 检查通过。
- 浏览器使用实际生产构建与模拟接口验证：真实来源标签、涨跌正负号、缺失及保留状态、路由切换复用缓存、移动端说明浮层边界、备用提示；设置页淡入有中间透明度与完成状态，弹窗通过 portal 避免被页面裁切。无页面 JavaScript 异常。

本地截图与原始验收输出保存于 `D:/Attention/reports/hithink-world-market-2026-10-22/`。接口模拟的 UI 验收不冒充真实生产数据验证。

## 覆盖与限制

当前世界市场包含 24 个标的，同花顺已验证替换 3 个 A 股指数；其余 21 项仍使用原来源。元数据检索“标普500”得到基金代码，不能当作境外指数实时报价。世界市场页面存在并不表示供应商已经完整覆盖该页面。

同花顺时间戳属于批次，Sina 精简接口未提供交易所时间；Yahoo 使用 `regularMarketTime`，数据库兜底仅提供收盘日期。它们都不能用 HTTP 接收时间或页面定时器伪造为“实时”。黄金与原油卡片代表期货，而非现货。

缓存随 Java 进程重启丢失；不新增全市场采集或持久行情缓存。更长周期稳定性、交易时段时效、许可、预算、境外替代来源及 K 线口径仍需进一步确认，旧数据库不能因此删除。

部署回执由 `backend/target/cloud-deployment.json` 生成；上线后另核对服务健康、静态资源校验和、供应商云端连通，以及原 DeepSeek 配置未改变。
