# 同花顺金融 API 指数能力复核

验证日期：2026-10-23。本次只从本机向数据商发起只读 REST 请求，未连接云端服务器，未删除数据库，未改变业务路由，也未部署。

## 结论

指数能力已存在。当前接口提供指数快照、日线、同花顺指数目录与当前成分股；标准宽基、概念和行业指数均有实测成功样本。历史网关已经使用指数日线接口，世界市场的三个国内指数也已经使用指数快照接口，不能将当前状态描述为尚未接入指数。

五年边界有官方契约依据，不只是项目自行设置。官方 REST 和 MCP 文档均规定指数历史区间位于近五年内。2019 年样本请求实际返回业务成功但空数组，不能把 `code=0` 单独视为数据覆盖成功。本次未证明任何其他公开接口能提供更早的指数历史；普通股票历史接口的年限不能套用于指数。

## 名称与代码必须动态核对

官方文档将 `886042.TI` 用作白酒概念示例，但本次概念目录返回：

- `886042.TI`：存储芯片。
- `885525.TI`：白酒概念。
- 行业目录中的 `881101.TI`：种植业与林业。

本次先取目录确认名称，再查询 `885525.TI` 的日线和成分股，两项均返回数据。接入应以目录或元信息检索结果绑定名称、代码，不能将文档示例的中文标签写死。历史无复权含义，不能以同名 ETF 的价格替代指数点位。

## 对 Investory 的影响

1. 近五年国内指数历史无需依赖旧 K 线表。下一步可扩展到更多宽基和板块，继续复用已有缓存与请求合并。
2. 当前网关对于跨越五年前边界的查询，整段交给备用通道。以后可考虑旧段使用备用来源、新段使用同花顺，前提是重叠日期的价格、成交量单位与标的身份校验一致；本次未实施。
3. 五年前指数历史仍是长周期回测的覆盖缺口。可以单独归档这部分历史，而不是因此保留整个 A 股个股日线抓取系统。归档价值须结合旧表实际覆盖确认。
4. 成分股查询只验证当前名单，不能用于无前视偏差的历史成分股回测。
5. 本机成功和低延迟不等于云端长期可靠。删除旧表前的生产隔离验收仍需单独完成。
